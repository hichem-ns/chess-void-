# CHESS//VOID

An experimental chess interface built around the idea of a **void move**: the moment where a normal position becomes unpredictable.

## Features
- Fully interactive chessboard
- Legal move validation via chess.js
- Move stream
- Material evaluation
- Check / checkmate state
- Threat radar
- Board flip
- Responsive mobile layout
- Experimental dark editorial visual system

## Run
Open `index.html` locally, or deploy the repository with GitHub Pages.

## GitHub Pages
Repository → **Settings** → **Pages** → Source: **GitHub Actions**.

The project can also be hosted with any static hosting provider.
